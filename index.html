Kebijakan Privasi Manting

Terakhir diperbarui: 23 Oktober 2026 · Berlaku untuk aplikasi Manting versi Google Play

Ringkasan

Manting adalah aplikasi kasir laundry yang bekerja sepenuhnya offline di perangkat Anda. Versi Google Play tidak mengumpulkan, tidak mengirim, dan tidak membagikan data apa pun ke server kami maupun pihak ketiga.

Data yang disimpan

Data pesanan, pelanggan, layanan, pengeluaran, dan pengaturan disimpan di database internal aplikasi pada perangkat Android Anda. Data tersebut tidak pernah dikirim ke internet.

Data yang dikumpulkan

  • Tidak ada data pribadi yang dikumpulkan.
  • Tidak ada analitik, iklan, pelacakan, atau profil pengguna.
  • Tidak ada data yang dibagikan ke pihak ketiga.
  • Tidak ada koneksi keluar dari aplikasi versi Google Play.

Izin yang digunakan

  • Bluetooth — mencetak struk ke printer thermal.
  • Lokasi (perkiraan) — hanya dibutuhkan sistem Android untuk memindai perangkat Bluetooth di sekitar; lokasi tidak direkam dan tidak dikirim.
  • Internet — tidak dipakai untuk mengirim data pada versi Google Play.

Cadangan data

Anda dapat mencadangkan data secara manual melalui menu Pengaturan > Backup & Pulihkan. Berkas cadangan dibuat di perangkat Anda dan sepenuhnya berada di bawah kendali Anda. Sistem cloud backup Android dinonaktifkan untuk aplikasi ini.

Penghapusan data

Menghapus aplikasi akan menghapus seluruh data yang tersimpan di perangkat. Tidak ada salinan data di server kami, karena data tidak pernah dikirim.

Anak-anak

Aplikasi ini ditujukan untuk pelaku usaha (18 tahun ke atas) dan tidak ditujukan untuk anak-anak.

Perubahan kebijakan

Kebijakan ini dapat diperbarui. Perubahan akan diumumkan pada halaman ini beserta tanggal pembaruan.
